# SO-101 5DOF 实机桥接第一阶段说明

本阶段提供四项能力：读取实机角度、单关节最多 `10°` 点动、读取并校验 IK 服务器保存的轨迹，以及仅针对全零参考姿态沿 `+Z` 移动约 `10 mm` 的受限实机执行。通用笛卡尔轨迹仍未开放。

## 已知配置

```text
机器人类型：so101_follower_5dof
串口：COM5
校准 ID：jiebang_follower_arm
舵机 ID：1、2、3、4、5
```

实机近似尺寸：J1→J2 为 55 mm，J2→J3 为 135 mm，J3→J4 为 135 mm，J4→J5 为 55 mm，J5→TCP 为 10 mm。方向和人工对齐零偏已经记录，但尺寸仍为近似值，因此 execute 只开放本说明限定的首次小范围测试。

## 1. 启动 IK 服务器

在已激活的 `lerobot` 环境中运行：

```powershell
cd E:\lerobot
lerobot-ik-sim --open_browser=true
```

浏览器打开 <http://127.0.0.1:8766>。输入目标坐标并规划后，页面会显示一个 32 位“规划编号”。服务器只保留最近 20 条成功规划，重启后编号失效。

## 2. 校验浏览器中的同一条路径

复制页面上的规划编号，然后在另一个终端运行：

```powershell
lerobot-ik-real --mode=dry-run --plan_id=页面显示的规划编号
```

该命令不访问 COM5，也不会下发舵机角度。只有规划成功、无自碰撞、包含 91 帧、所有数值有效且相邻帧变化不超过 `1°` 时才通过。输出中的：

```json
"cartesian_execution_locked": true
```

表示 dry-run 本身不会控制实机；真正执行必须另外使用受限 `execute` 模式并显式确认。

也可以不经过网页，直接让实机桥接程序请求服务器规划并校验：

```powershell
lerobot-ik-real `
  --mode=dry-run `
  --target_x=0.0305 `
  --target_y=-0.1798 `
  --target_z=0.1762 `
  --max_frame_step_deg=1.5
```

该已验证示例的最大单帧变化约为 `1.398°`，因此显式使用 `1.5°` dry-run 门槛；默认 `1°` 会按设计拒绝它。不要仅为了让其他目标通过而随意放宽门槛。

## 3. 只读取实机姿态

先让机械臂空载，移除周围障碍物，保持可以立即断电，然后运行：

```powershell
lerobot-ik-real --mode=inspect
```

程序使用现有 `jiebang_follower_arm` 校准文件，读取五个关节的当前角度并断开连接。它不会调用 `send_action`，也不会重新校准。

## 4. 单关节微动

每次只测试一个关节，建议先用 `1°` 确认正方向。程序允许的固定硬上限为 `10°`：

```powershell
lerobot-ik-real `
  --mode=jog `
  --joint=shoulder_pan `
  --delta_deg=1
```

可用关节名：

```text
shoulder_pan
shoulder_lift
elbow_flex
wrist_flex
wrist_roll
```

单次增量必须位于 `[-10°, 10°]` 且不能为零。程序只写入一次，不自动回到原位，并在等待 `0.8 s` 后读取反馈角度。若方向不符合预期、出现异响、卡滞或过流，应立即断电并停止后续测试。

## 5. 当前不能做的事

- 不能执行任意浏览器轨迹；只允许经过 execute 专用约束的全零起点 `+Z 10 mm` 轨迹。
- 不能绕过已测方向、零偏和首帧实机反馈检查。
- 不能用当前近似尺寸证明实机 TCP 会准确到达仿真坐标。
- 不能把 IK 自碰撞检查当作环境避障或动力学安全验证。

完成本次 `+Z 10 mm` 测试并测量实际 TCP 位移后，仍需复测精确尺寸和映射误差，才能逐步扩大通用轨迹范围。

## 6. 已实测的关节方向

2026-08-02 使用实机 `+5°` 单关节点动得到：

| URDF 关节 | LeRobot 关节 | 实物观察结果 | URDF 映射符号 |
|---|---|---|---:|
| `J1_Rotation` | `shoulder_pan` | 从上往下看顺时针 | `+1` |
| `J2_Shoulder_Pitch` | `shoulder_lift` | 大臂上升 | `+1` |
| `J3_Elbow_Pitch` | `elbow_flex` | 肘部夹角变小 | `+1` |
| `J4_Wrist_Pitch` | `wrist_flex` | 末端向下低头 | `+1` |
| `J5_Wrist_Roll` | `wrist_roll` | 从 TCP 朝舵机看顺时针 | `+1` |

方向映射因此暂定为 `[+1, +1, +1, +1, +1]`。该结果只确认角度增量的正负方向；在确定五轴零位偏移前，仍不能直接把 URDF 绝对角度当作实机目标角度。

## 7. 已测零位偏移

将实机姿态与浏览器 `[0°, 0°, 0°, 0°, 0°]` 姿态对齐后，实机读取值为：

| URDF 关节 | LeRobot 关节 | URDF 参考角 | 实机参考角 | 零位偏移 |
|---|---|---:|---:|---:|
| `J1_Rotation` | `shoulder_pan` | `0°` | `7.076923°` | `+7.076923°` |
| `J2_Shoulder_Pitch` | `shoulder_lift` | `0°` | `0.703297°` | `+0.703297°` |
| `J3_Elbow_Pitch` | `elbow_flex` | `0°` | `1.626374°` | `+1.626374°` |
| `J4_Wrist_Pitch` | `wrist_flex` | `0°` | `16.747253°` | `+16.747253°` |
| `J5_Wrist_Roll` | `wrist_roll` | `0°` | `-14.549451°` | `-14.549451°` |

由于五轴方向符号均为 `+1`，映射公式为：

```text
实机角度 = URDF 角度 + 零位偏移
URDF 角度 = 实机角度 - 零位偏移
```

零位偏移向量为：

```text
[7.076923, 0.703297, 1.626374, 16.747253, -14.549451]°
```

这组数值来自一次人工姿态对齐，暂作为首阶段映射值。开放轨迹执行前仍需使用“映射后的首帧目标与实机当前反馈之差”进行启动校验，不能无条件跳到轨迹第一帧。

## 8. 首次受限实机执行

### 8.1 重启服务器并生成新规划

必须停止旧服务器并使用当前代码重新启动：

```powershell
lerobot-ik-sim --open_browser=true
```

浏览器保持五关节全零起点，目标坐标填写：

```text
X = 0.005534
Y = -0.179839
Z = 0.171219
```

当前近姿态规划的预期结果约为：

```text
J1 = -0.149°
J2 =  0.812°
J3 =  0.942°
J4 = -4.069°
J5 =  0.000°
位置误差 = 0.180 mm
```

如果页面仍显示约 `49°/62°/74°` 的大幅角度，说明仍在使用旧服务器，禁止执行。

### 8.2 dry-run 同一规划

复制页面的新规划编号：

```powershell
lerobot-ik-real --mode=dry-run --plan_id=<规划编号>
```

应看到 91 帧、无碰撞，最大单帧变化约 `0.085°`。dry-run 不连接 COM5。

### 8.3 检查实机起点

```powershell
lerobot-ik-real --mode=inspect
```

当前读数应分别接近零偏 `[7.076923, 0.703297, 1.626374, 16.747253, -14.549451]°`，每个关节允许的最大差值为 `2°`。execute 还会自动复查，超限时不发送任何动作。

### 8.4 执行

机械臂必须空载、周围无障碍物，并保持可以立即断电。确认后运行：

```powershell
lerobot-ik-real `
  --mode=execute `
  --plan_id=<同一个规划编号> `
  --confirm_execute=true
```

程序以 `10 Hz` 执行剩余 90 帧，每帧读取反馈。反馈误差超过 `3°`、命令被限幅、通信异常或任何安全校验失败都会中止并断开；成功或失败均不自动回程。
